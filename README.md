# 1PNSimulation
Simulation of 2 body problem at first order in post newtonian expansion.

1PN.ipynb contains the code for the simulation. In the Mathematica file, I derive the 1PN equation of motion that is subsequently implemented within the python notebook.
Additionally, there are a few gifs of a handful of different scenarios. At 1PN, we expect to see orbital precession but no gravitational radiation, which is exactly
what we see. The gifs go for different durations, and some are equal mass ratio and others are unequal mass ratio. Recall that the post-Newtonian expansion is one of v/c.
In 1PNUnEqualMassSmallc.gif, I make the c very small, or in other words v/c~1. Watch that simulation and see how the exansion breaks down!
